## 4. TECHNICAL SEO

### Canonical URL
```html
<link rel="canonical" href="https://poliinternational.com/standalone-tools/touch-up-timeline/">
```
- Prevents duplicate content issues
- Consolidates link equity
- Essential for embed version

### Robots Directives
```html
<meta name="robots" content="index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1">
```
- **index, follow**: Full crawling allowed
- **max-image-preview:large**: Shows large images in search
- **max-snippet:-1**: Unlimited text snippet length
- **max-video-preview:-1**: Unlimited video preview

### Mobile Optimization
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="theme-color" content="#3B82F6">
<meta name="apple-mobile-web-app-capable" content="yes">
```

- Responsive design (Google Mobile-First Indexing)
- PWA-ready
